# pomodoro-simple-ver
Hi. This is a simple pomodoro timer.
### ⏰Purpose of me make this small project:
I just want to play around with DOM manipulation.

### 🔗Feel free to use the pomodoro timer in the link below⬇️
https://thatskana.github.io/pomodoro-simple-ver/

### 🎀How to use
1. By default the timer is set to 25 minutes.
2. You can edit the timer according to your preference by clicking the timer.
3. How to start the timer:
   - by pressing enter after you done input your time
   - or by clicking the start button
4. How to pause: you can pause the timer by clicking the pause button
5. Then you can start the timer again by click the start button
6. When the timer finish, a short ringtone will be played.
7. How to reset: by clicking the reset button
8. It will reset to how you first input and start your timer.
